# Seguro del proveedor 1: API

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** el rubro pide seguro, la invitación guarda compañía, póliza y vencimiento, y la barrera rechaza `no_insurance` o `insurance_expired`, salvo que el guardia cargue el seguro al registrar el ingreso.
**Architecture:**
- columnas nuevas en `trade`, `invitation` y `neighborhood`;
- la lógica pura en `api/src/lib/seguro.ts`;
- `canEnter` recibe el estado ya resuelto.
**Tech Stack:** Express 5, Drizzle, PostgreSQL 16, zod, vitest.
**Spec:** `docs/superpowers/specs/2026-10-21-seguro-proveedor-design.md`. Le sigue el plan 2 (web).

## Global Constraints

- Hora de Buenos Aires siempre (`lib/dates.ts`).
- `canEnter` sigue siendo puro. `no_insurance` e `insurance_expired` van **después de `no_capacity`**.
- El `FOR UPDATE` de `registerEntry` no se toca. El seguro que manda el guardia se guarda después del lock y antes de `canEnter`.
- Errores: `AppError(status, 'codigo_en_snake')`. El seguro va completo (los tres campos) o en null.
- La página pública nunca devuelve los datos del seguro, solo `insuranceState`.
- Nombres y comentarios en español; el esquema y las rutas, en inglés.
- Verificar: `cd api && npm test && npx tsc --noEmit`. Nunca dos `npm test` a la vez: comparten la base.

- [ ] **Step 4: implementación** (`src/lib/seguro.ts`):

```ts
import { todayInBuenosAires } from './dates.js'
import { aplicaFranjas } from './franjas.js'

export type Seguro = { company: string; policy: string; expiresOn: string }

/** Lo pide quien entra a trabajar (como las franjas) y solo si su rubro lo pide. Sin rubro, no. */
export function pideSeguro(kind: string, frequentAs: string | null, tradeRequiresInsurance: boolean | null): boolean {
  return aplicaFranjas(kind, frequentAs) && tradeRequiresInsurance === true
}

export function seguroCompleto(company: string | null, policy: string | null, expiresOn: string | null): boolean {
  return Boolean(company?.trim() && policy?.trim() && expiresOn)
}

/** 'YYYY-MM-DD' comparado como string: vale el día del vencimiento entero. */
export function seguroVigente(expiresOn: string, now: Date): boolean {
  return expiresOn >= todayInBuenosAires(now)
}
```
