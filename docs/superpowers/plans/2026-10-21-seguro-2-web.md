# Seguro del proveedor 2: web

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que el admin configure qué rubros piden seguro y vea los vencimientos, que el vecino y el proveedor lo carguen, y que la garita frene al proveedor y deje cargarlo en el veredicto.
**Architecture:** la lógica pura va en `web/src/lib/seguro.ts` con su check, y los componentes solo la muestran. Los datos salen de la API del plan 1.
**Tech Stack:** Next.js 16, React 19, Tailwind v4, TanStack Query, Playwright.
**Spec:** `docs/superpowers/specs/2026-10-21-seguro-proveedor-design.md`. **Requiere** el plan 1. Mockups: `.superpowers/brainstorm/4655-1792626562/content/seguro-plano-v1.html`, secciones 3, 4 y 5. En la 4, **sin** agrupar por póliza: una fila por invitación.

## Global Constraints

- Colores solo de los tokens de `globals.css`. Textos en voseo. Admin y garita desktop-first; vecino e invitado mobile-first.
- Hora de Buenos Aires: `lib/fechas.ts` (`hoyISO`). Nunca `new Date()` para calcular un día.
- Errores: cada mutación traduce los códigos de la API a texto.
  - `seguro_no_aplica` → "Este rubro no pide seguro."
  - `no_insurance` → "Sin seguro"
  - `insurance_expired` → "Seguro vencido"
- El seguro va completo o vacío: si se llena un campo, se piden los tres.
- Verificar: `cd web && npm run check && npm run lint && npx tsc --noEmit`. El e2e corre con `--workers=1` y el stack levantado (`docker compose up -d --build`).

- [ ] **Step 1: check que falla:**

```ts
/** `node src/lib/seguro.check.ts`. */
import assert from 'node:assert/strict'
import { estadoSeguro, textoVence } from './seguro.ts'
const s = (expiresOn: string | null, requiresInsurance = true) =>
  ({ requiresInsurance, insuranceCompany: expiresOn && 'La Segunda', insurancePolicy: expiresOn && '4471-22', insuranceExpiresOn: expiresOn })
const HOY = '2026-10-21'
assert.equal(estadoSeguro(s('2027-01-01', false), HOY, 15), 'no_aplica')
assert.equal(estadoSeguro(s(null), HOY, 15), 'sin_cargar')
assert.equal(estadoSeguro(s('2026-10-20'), HOY, 15), 'vencido')
assert.equal(estadoSeguro(s('2026-10-21'), HOY, 15), 'por_vencer')   // vence hoy: vale, pero avisa
assert.equal(estadoSeguro(s('2026-11-05'), HOY, 15), 'por_vencer')   // 15 días justos
assert.equal(estadoSeguro(s('2026-11-06'), HOY, 15), 'vigente')
assert.equal(estadoSeguro(s('2026-10-22'), HOY, null), 'vigente')    // sin aviso configurado
assert.equal(textoVence('2026-10-26', HOY), 'vence en 5 días (26/10)')
assert.equal(textoVence('2026-10-22', HOY), 'vence mañana (22/10)')
assert.equal(textoVence('2026-10-21', HOY), 'vence hoy')
assert.equal(textoVence('2026-10-12', HOY), 'venció el 12/10')
console.log('seguro: ok')
```

El check queda en verde con `npm run check`.
